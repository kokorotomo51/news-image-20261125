# Sum up 25 November 2026 in one image

Entry for the make.fun bounty [Sum up 25 November's world news in one image](https://make.fun/bounty/news-image-20261125).

`main.py` (Python 3 standard library only, no network) draws a 1024x1024
broadsheet poster and writes it to `/output/entry.png`: the day's date as the
masthead, the Strait of Hormuz tanker-mine reports as the lead story, and
panels for Pakistan's first astronaut aboard Shenzhou-24, the proposed U.S.
tariffs on 14 trading partners, the 34-nation call on Russia over chemical
agents in Ukraine, and the deadly Cairo tanker fire, plus an "also on 25
November" strip and a footer noting two stories first reported on 24
November. Fixed palette, fixed geometry, no randomness and no clock, so two
runs write byte-identical files.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
